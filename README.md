# VLab

A deliberately vulnerable web application built to practice, understand, and exploit real-world web vulnerabilities.

## About

**VLab** is a collection of intentionally vulnerable web applications and challenges designed for hands-on learning of web security.

Unlike generic vulnerable applications, VLab focuses on vulnerabilities that I find particularly interesting, allowing deeper exploration of exploitation techniques, root causes, and secure remediation.

---

## Vulnerabilities

The project will include the following labs:

- Broken Access Control
- Insecure Direct Object Reference (IDOR)
- Authentication Bypass
- Server-Side Request Forgery (SSRF)
- Command Injection
- File Upload Vulnerabilities
- File Inclusion (Local & Remote)
- Path Traversal
- JWT Vulnerabilities
- Race Conditions
- Business Logic Vulnerabilities
- HTTP Request Smuggling
- Web Cache Poisoning
- Host Header Attacks

---

## Disclaimer

This project is intentionally insecure.

**Do not deploy VLab on public-facing servers.**

Run it only in isolated local environments, virtual machines, or dedicated lab networks.

The project is intended solely for educational and research purposes.
